Local-first by design

PatchPlus is being designed around a simple principle: a developer's source code should remain under the developer's control. The current product direction is to perform repository analysis locally rather than requiring source code to be uploaded to a central server.

Prototype status: PatchPlus is currently under development. Features and architecture may evolve as the system is validated with developers.
